# G.L.T. GARMENTS website
Open the folder in VS Code, then open index.html with the Live Server extension (or double-click it).
- Edit shop numbers, prices and products in `js/data.js`.
- Put real photos in `images/products/` named jogging.jpg, pe.jpg, polo.jpg, round.jpg, vneck.jpg, jersey.jpg (sample pictures show until you do).
- Admin: `admin/login.html`, user `admin`, password `glt2026` (demo only, not real security).
- Orders are saved in the browser (localStorage).
- GitHub Pages: push to GitHub, then Settings > Pages > Deploy from branch > main > /root.
